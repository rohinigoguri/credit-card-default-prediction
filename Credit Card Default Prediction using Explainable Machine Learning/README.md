# Credit Card Default Prediction Using Explainable Machine Learning

## Overview

Credit Card Default Prediction Using Explainable Machine Learning is a web-based application that predicts whether a customer is likely to default on their credit card payment in the following month. The system analyzes customer financial and demographic information and provides risk assessment along with explainable AI insights.

The project combines machine learning, data preprocessing, class imbalance handling using SMOTE, and SHAP explainability to support transparent and reliable credit risk prediction.

---

## Features

### Batch Prediction

* Upload CSV or Excel files containing customer information.
* Predict default risk for multiple customers simultaneously.
* Download prediction results as CSV files.
* Display probability scores and risk levels.

### Manual Prediction

* Enter customer details through a user-friendly web interface.
* Predict whether a customer is likely to default or not.
* Display default probability and risk classification.

### Explainable AI

* SHAP-based feature importance visualization.
* Shows factors contributing to prediction outcomes.
* Improves transparency and trust in machine learning decisions.

### Risk Classification

* Low Risk (< 30%)
* Medium Risk (30% – 70%)
* High Risk (> 70%)

### Web Application

* Flask-based interactive user interface.
* Supports both manual and batch predictions.
* Provides explainable AI insights through SHAP.

## Dataset

The project uses the **Default of Credit Card Clients Dataset**, which contains customer demographic information, credit limits, repayment history, bill statements, and payment records.

### Important Features

* LIMIT_BAL
* SEX
* EDUCATION
* MARRIAGE
* AGE
* PAY_0 to PAY_6
* BILL_AMT1 to BILL_AMT6
* PAY_AMT1 to PAY_AMT6

### Target Variable

* 1 = Default
* 0 = Not Default

## Model Performance

Multiple machine learning algorithms were evaluated:

* Logistic Regression
* Decision Tree
* Random Forest

The Random Forest model achieved the best overall performance and was selected as the final prediction model.
